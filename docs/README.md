# WPKN Radio Archive Player

This is a web-based player for accessing the WPKN radio archive recordings. Features include:

- Browsing and searching through archived recordings
- Audio playback with play/pause, seek, and volume controls
- Responsive design that works on desktop and mobile devices
- Secure access to recordings stored in AWS S3

## Usage

Visit [https://cosentinoeli.github.io/wpkn-archives/](https://cosentinoeli.github.io/wpkn-archives/) to access the player.

## Technical Details

- Built with vanilla JavaScript and modern web standards
- Uses AWS Cognito for secure, anonymous access to recordings
- Leverages HTML5 Audio API and Howler.js for reliable playback
- Supports all modern browsers
